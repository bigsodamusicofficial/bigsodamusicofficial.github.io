How to Use

  1. Select an image file from your computer using the file input above
  2. The image will be displayed in the preview and converted to a data URL
  3. Click "Copy to Clipboard" to copy the data URL
  4. Click "Update Preview Cube" to see the image on the cube
  5. Paste the data URL into your Three.js project as the image source

Next Steps

After copying the data URL, you can use it in your Three.js portfolio by:

  1. Opening single-image-demo.html
  2. Find the portfolioDatabase array in the JavaScript code
  3. Replace one of the image URLs with the data URL you copied
  4. Save the file and reload it in your browser
